# Arithmetic Operators Example

This project contains a simple C++ exercise demonstrating the use of arithmetic operators.

## Description

The `main.cpp` file includes a function `arithmetic_operators` which performs a sequence of mathematical operations on an integer using common C++ arithmetic operators:
- Multiplication (`*`)
- Addition (`+`)
- Subtraction (`-`)
- Division (`/`)
- Modulo (`%`)

The code demonstrates how to manipulate a single integer by applying these operators sequentially, updating its value at each step using the assignment operator (`=`).

## How to Build and Run

You will need a C++ compiler installed on your system (such as GCC, Clang, or MSVC). 

### Using GCC / G++

1. Open your terminal or command prompt.
2. Navigate to the project directory:
   ```bash
   cd path/to/Arithmetic_Operators
   ```
3. Compile the code using `g++`:
   ```bash
   g++ main.cpp -o arithmetic_operators
   ```
4. Run the compiled executable:
   - On Windows:
     ```cmd
     arithmetic_operators.exe
     ```
   - On Linux/macOS:
     ```bash
     ./arithmetic_operators
     ```

*(Note: Currently, the `main` function is empty. To see the output, you can add a call to `arithmetic_operators(some_number)` and print the result inside the `main` function before compiling.)*
