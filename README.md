# C++ Examples Repository

This repository contains a collection of C++ examples and exercises to demonstrate various features of the language.

## Available Examples

Here is a list of the different examples available in this repository:

- **App1** / **App2** - Basic application setups
- **Arithmetic_Operators** - Demonstrates multiplication, addition, subtraction, division, and modulo operations
- **Arrays** / **Array_Vectors** / **Vectors** / **Vector_Challenge** - Working with arrays and vectors in C++
- **Basic_IO** - Basic input and output streams
- **C_Plus_Plus_String** / **Char_Strings** - Working with C-style strings and C++ `std::string`
- **Classes** / **Classes_Objects** / **OOP** - Object-Oriented Programming, classes, and objects
- **Constants** - Using constants in C++
- **Constructors**
  - **Constractor_Initialization_List**
  - **Copy_Constractor**
  - **Default_Constractor_Prameters**
  - **Delegating_Constractor**
  - **Shallow_vs_Deep_Copy_Constractor**
- **Control_Program_Flow** - If statements, loops, and control flow
- **Dynamic_Memory_Allocation** - New and delete operators
- **Functions** - Defining and calling functions
- **Pass_By_Referance** / **Pass_By_Referance_In_C** - Passing arguments by reference
- **Pointers** - Working with memory addresses and pointers
- **SizeOfOperator** - Using the `sizeof` operator
- **Sum_oF_Digits** - Algorithm example

## How to Build and Run an Example

You will need a C++ compiler installed on your system (such as GCC, Clang, or MSVC). 

### Using GCC / G++

1. Open your terminal or command prompt.
2. Navigate to the project directory for the example you want to run. For instance:
   ```bash
   cd Arithmetic_Operators
   ```
3. Compile the code using `g++` (most examples have a `main.cpp`):
   ```bash
   g++ main.cpp -o example_app
   ```
4. Run the compiled executable:
   - On Windows:
     ```cmd
     example_app.exe
     ```
   - On Linux/macOS:
     ```bash
     ./example_app
     ```
